把照片/视频放到这个文件夹，然后去上级目录的 `game.js` 里修改 `mediaList`。

本项目支持“一键重命名为英文短名”：
- 运行 `web_toddler_bubbles/rename_assets.ps1`
- 图片会变成：p01.jpg、p02.jpg...
- 视频会变成：v01.mp4、v02.mp4...

示例（把文件名改成你自己的）：
- 照片：photo1.jpg、photo2.png
- 视频：video1.mp4（建议短一点；手机端通常需要静音才能自动播放）

注意：
1) GitHub Pages 上可正常加载这些静态文件。
2) 文件名大小写要一致（尤其在部分环境下）。
